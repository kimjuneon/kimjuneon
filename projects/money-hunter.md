## 핵심 기여

### 운영 중 변경 가능한 게임 정책

- 성장, 자동사냥, 던전, 보상 정책을 서비스 운영 중에도 변경할 수 있는 구조로 설계했습니다.
- 정책 변경이 핵심 도메인 로직에 미치는 범위를 줄이는 데 집중했습니다.

### 인증·결제·보상 흐름

- Toss 로그인과 IAP 흐름을 연동했습니다.
- 광고 보상 세션과 프로모션 흐름을 구현해 보상 처리 경계를 명확히 했습니다.

### 배포와 운영 지표

- 관리자 API와 접속·리텐션 지표를 구축했습니다.
- Docker와 GitHub Actions를 활용해 Cloud Run 배포·운영 흐름을 구성했습니다.
